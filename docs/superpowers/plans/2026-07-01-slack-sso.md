# Slack SSO (Identity) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add "Sign in with Slack" to the web app so the logged-in user is the same `User` row that gives/receives kudos in Slack, replacing the fake "highest-balance user."

**Architecture:** Auth.js (NextAuth v5) with the Slack OIDC provider in `apps/web`, JWT sessions. Identity linking is centralized in a new `@kudos/db` `linkSlackUser()` that both the web login and the Slack bot use. A `getCurrentUser()` server helper resolves the session to a DB `User`.

**Tech Stack:** TypeScript, `@kudos/db` (Prisma), Next.js 14 App Router, `next-auth@5.0.0-beta.25`, Vitest.

## Global Constraints

- ESM everywhere; `@kudos/db` imports use `.js` extensions; **web-internal** imports are extensionless (Next resolves `.ts`/`.tsx`).
- DB access ONLY through `@kudos/db`.
- **Link identity on the `https://slack.com/user_id` OIDC claim** (the `Uxxxx` id the bot stores) — NOT the generic `sub`. If that claim is absent, fail the sign-in.
- Session strategy: **JWT** (no session DB table). The token carries `userId` = internal `User.id`.
- Secrets live in `apps/web/.env.local` (gitignored via `.env.*`); only `.env.local.example` is committed. Never commit real secrets.
- Pin `next-auth@5.0.0-beta.25`.
- `linkSlackUser` preserves the bot's existing behavior: match by `slackUserId` → else link an unlinked (`slackUserId: null`) user with the same `name` → else create on the demo team.
- Commit after every task's tests pass.

```ts
import { prisma } from "./client.js";

export async function linkSlackUser(input: {
  slackUserId: string; name: string; email?: string | null; avatarUrl?: string | null;
}): Promise<{ id: string }> {
  const { slackUserId, name, email, avatarUrl } = input;

  const linked = await prisma.user.findUnique({ where: { slackUserId } });
  if (linked) {
    const updated = await prisma.user.update({
      where: { id: linked.id },
      data: { name, ...(email ? { email } : {}), ...(avatarUrl ? { avatarUrl } : {}) },
    });
    return { id: updated.id };
  }

  const unlinkedByName = await prisma.user.findFirst({ where: { slackUserId: null, name } });
  if (unlinkedByName) {
    const updated = await prisma.user.update({
      where: { id: unlinkedByName.id },
      data: { slackUserId, ...(email ? { email } : {}), ...(avatarUrl ? { avatarUrl } : {}) },
    });
    return { id: updated.id };
  }

  const team = await prisma.team.findFirstOrThrow();
  const created = await prisma.user.create({
    data: { slackUserId, name, email: email ?? null, avatarUrl: avatarUrl ?? null, teamId: team.id },
  });
  return { id: created.id };
}
```

- [ ] **Step 2: Create `apps/web/auth.ts`**

```ts
import NextAuth from "next-auth";
import Slack from "next-auth/providers/slack";
import { linkSlackUser } from "@kudos/db";

export const { handlers, auth, signIn, signOut } = NextAuth({
  providers: [
    Slack({
      clientId: process.env.AUTH_SLACK_ID,
      clientSecret: process.env.AUTH_SLACK_SECRET,
    }),
  ],
  session: { strategy: "jwt" },
  callbacks: {
    async signIn({ user, profile }) {
      const slackUserId = (profile as Record<string, unknown>)?.["https://slack.com/user_id"] as string | undefined;
      if (!slackUserId) return false; // must link on the Slack user id, not `sub`
      const linked = await linkSlackUser({
        slackUserId,
        name: user.name ?? "teammate",
        email: user.email ?? null,
        avatarUrl: user.image ?? null,
      });
      (user as { dbId?: string }).dbId = linked.id;
      return true;
    },
    async jwt({ token, user }) {
      if (user) token.userId = (user as { dbId?: string }).dbId;
      return token;
    },
    async session({ session, token }) {
      if (token.userId && session.user) {
        (session.user as { id?: string }).id = token.userId as string;
      }
      return session;
    },
  },
});
```

- [ ] **Step 1: Create `apps/web/lib/current-user.ts`**

```ts
import { auth } from "../auth";
import { prisma } from "@kudos/db";

export async function getCurrentUser() {
  const session = await auth();
  const id = (session?.user as { id?: string } | undefined)?.id;
  if (!id) return null;
  return prisma.user.findUnique({ where: { id } });
}
```
