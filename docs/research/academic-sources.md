## Refuted in verification (do NOT cite as support)

- "Intrinsic and extrinsic motivation are positively correlated (.22), so no tradeoff" — **refuted 0-3**.
- "Witnessing recognition increases observer's own work engagement (B=0.101)" — **refuted 0-3**. (The *justice* mediation survived; the engagement spillover did not.)
- "Dunbar's ~150 is a firm neocortex-derived cognitive ceiling" — **refuted 0-3** (pass-3). Treat 150 as a soft zone.
- "Groups spontaneously fragment above ~20 members" — **refuted 0-3** (pass-3).
