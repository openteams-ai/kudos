# Research

This folder holds the evidence base for the product's design. The goal: every major design decision (points model, nudges, gamification mechanics, notification cadence) should trace to real behavioral-science research, not vibes.

## Planned outputs

1. **`behavioral-research-report.md`** — synthesized, cited findings from the deep-research pass across:
   - Nudge theory / behavioral economics (choice architecture, glanceable feedback, streaks, defaults)
   - Self-Determination Theory & motivation (intrinsic vs extrinsic, overjustification / crowding-out)
   - Empirical employee & peer recognition research (participation drivers, frequency, public praise)
   - Enterprise gamification (which mechanics sustain engagement vs cause gaming/fatigue)
   - Habit-formation frameworks (Fogg Behavior Model, Hooked / trigger-action-reward-investment)
   - Pitfalls & anti-patterns (inflation, favoritism gaming, notification fatigue, reward backfire)

2. **`academic-sources.md`** — primary peer-reviewed citations with DOIs and open-access links (legitimate sources only; no Sci-Hub — see decision D11).

3. **`design-implications.md`** — the bridge: each research finding → concrete design decision in the product.
